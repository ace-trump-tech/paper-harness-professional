# paper-harness-cv

**言語:** [简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

> ローカル知識ベース、A+B+C の研究アイデア、GPU ごとの子 Agent、指標評価、証拠に結び付いた執筆を扱う CV 向け Auto-Research harness です。

GPU 実験はデフォルトで dry-run です。実際の学習には、承認済みのリポジトリ、データセット、runtime、予算、実験設定が必要です。指標を捏造したり、アイデアを自動で検証済みの貢献として扱ったりしません。

詳細は [CV workflow notes](docs/cv-exploration-zh.md) を参照してください。
