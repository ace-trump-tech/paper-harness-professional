# paper-harness-professional

**言語:** [简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

> 専門研究者向けの Auto-Research harness です。CV 探索と電力網の具身知能制御を中心に、ローカル知識ベース、組合せ探索、GPU ごとの実験、指標評価、証拠付き執筆を扱います。

GPU 実験はデフォルトで dry-run です。実際の学習には、承認済みのリポジトリ、データセット、runtime、予算、実験設定が必要です。指標を捏造したり、アイデアを自動で検証済みの貢献として扱ったりしません。

詳細は [CV workflow](docs/cv-exploration-zh.md)、[電力網 Demo](demo/self-learn/README.md)、[harness architecture](docs/harness-architecture-zh.md) を参照してください。

汎用・学部生版は [paper-harness-undergraduate](https://github.com/ace-trump-tech/paper-harness-undergraduate) で管理しています。2 つのリポジトリで paper-harness 全体を構成します。
