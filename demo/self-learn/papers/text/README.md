# Extracted Text Corpus

The extracted text files are retrieval targets, not replacements for the original papers. Each includes page markers so a later reader can return to the source PDF. Only complete PDFs that `pypdf` can open are represented here.

At the current snapshot, `powergym.txt` was produced from a verified 19-page source PDF. Other selected references remain indexed in `metadata/source-manifest.json` until their transfer is validated.
