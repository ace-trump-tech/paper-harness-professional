# 从零到可审计研究：学习路径

这条路径面向完全不了解电网具身智能的人。它的目标不是背算法，而是能读懂一个控制闭环、复现一个小型基准、提出可证伪的问题，并把证据整理成论文。顶刊发表取决于问题价值、方法新颖性、实验严谨性和同行评审，知识库不能替代这些环节。

## 阶段 0：先建立边界（半天）

阅读：`research-map.md`、`corpus-index.md`、`knowledge/cards/embodied-industrial-control-2026.md`。

必须能回答：Agent 观察什么、改变什么、环境如何反馈、谁验证动作、谁拥有最终执行权。若答不清楚，不进入算法比较。

## 阶段 1：电力系统与控制对象（1 天）

阅读：PowerGym、Gym-ANM、Grid2Op 卡片；再看相应 PDF 的方法和环境定义章节。

练习：画出一个“观测 -> 决策 -> 潮流/仿真 -> 反馈”的闭环，标出状态、动作、约束、时间步长和不可观测量。

检查点：能区分配电网 Volt-Var、输电网拓扑控制、微网能量管理三类任务。

## 阶段 2：多 Agent 与安全（1 天）

阅读：PowerGridworld、CommonPower、safe-RL review 卡片。

练习：为每个动作写出合法域、拒绝/投影机制和失败恢复路径；同时记录“奖励惩罚”不等于“硬安全保证”。

检查点：能说清集中式、分散式和带安全门控策略的差别。

## 阶段 3：复现基线（2--5 天）

从 `experiment-blueprint.md` 选择一个环境和一个动作类。先跑随机/规则策略，再跑 OPF/MPC（若环境支持），最后跑一个标准 RL 策略。固定数据切分、种子、软件版本和预算。

检查点：结果中同时有平均收益、约束违例率、违例严重度、恢复时间、延迟和动作拒绝率。

## 阶段 4：提出 A+B+C 研究假设（1--2 天）

从 `innovation-bank.md` 选择一个明确瓶颈，再组合最多三个互补模块，例如“预测不确定性 + 安全投影 + 多时间尺度协调”。为每个模块写：改变什么、保持什么不变、怎样证伪、需要哪些对照。

检查点：创新不是“换一个算法名”，而是可测量的机制变化；若没有消融和公平基线，不能称为贡献。

## 阶段 5：压力测试与论文证据（持续）

按 `experiment-blueprint.md` 做分布外负荷/PV、传感器噪声、通信延迟、故障和动作冷却测试。再用 `agent-protocol.md` 让 Agent 生成 claim-证据表、反驳清单和论文大纲。

发布前检查：每一句关键结论都有论文、数据或运行 artifact；每个图表有生成脚本和版本；安全结论写明适用假设和未覆盖故障；代码和数据许可可再分发。
